#  Sales Analysis using Python

This project analyzes sales data using Python to identify business trends and category-wise performance. Multiple Excel datasets are merged, cleaned, and analyzed to generate meaningful insights through data visualization.

## Features

- Import and merge multiple Excel datasets
- Clean and preprocess the data
- Calculate sales, profit, and profit margin
- Perform category-wise sales analysis
- Visualize sales and profit margin using bar charts
- Generate business insights based on the analysis

## Tech Stack

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Structure

```
├── Sales_Analysis.ipynb
├── List_of_Orders.xlsx
├── Order_Details.xlsx
├── Sales_target.xlsx
└── README.md
```

## How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Sales-Analysis.git
cd Sales-Analysis
```

2. Install the required libraries

```bash
pip install pandas matplotlib openpyxl
```

3. Open the notebook

```bash
jupyter notebook Sales_Analysis.ipynb
```

4. Run all the cells to reproduce the analysis and visualizations.
